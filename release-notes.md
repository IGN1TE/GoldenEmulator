GoldenEmulator 0.9.0 — Library Hub

All 15 requested feature areas are included:

1. Artwork and metadata lookup from Wikipedia/Wikidata, with selectable matches and source attribution.
2. Watched folders with optional scans every minute and review before importing new games.
3. Missing-file detection, exact portable-path repair previews and manual locate.
4. Per-game emulator EXE, configuration file and literal launch arguments.
5. Process-based playtime and recent session history.
6. Custom collections and collection filtering.
7. Couch mode with larger cards/controls and fullscreen access.
8. Controller shortcuts: Y/Triangle search with an on-screen keyboard, X/Square Hub, Start/Menu collections; return focus after emulator exit.
9. Dated save ZIP backups, optional backup before launch, and restore with a safety backup first.
10. Multi-disc grouping with individual disc selection on the game page.
11. Emulator executable health checks and setup requirement guidance.
12. Launch/exit/error diagnostics with JSON export.
13. Update release notes, explicit installation action, download progress and verification status.
14. Watched-folder-relative game paths and moved-drive reconnection with reviewed repairs.
15. Expanded game pages with screenshots, rating, completion status, description, genre, year and notes.

Hub exports and descriptive metadata restoration are included. Existing library, console configuration, themes, dashboards, audits and exports remain available.

Use the Hub button in the toolbar. Open any game, then choose Game page & settings. Link your own installed emulators and game files as before.

Scope: metadata requires internet and provider coverage varies. Watched folders run only while GoldenEmulator is open. Playtime measures the launched emulator process, including menus/pauses, while the app remains open; hand-off launchers and PS5 are not timed. Save folders must be selected for each game; restore replaces matching files and retains unrelated files. Backups are limited to 1 GB/20,000 files. Grouping selects discs; disc swapping inside a running game remains the emulator's job. Firmware guidance is not automatic BIOS validation. Portable paths require reconnecting watched folders on the new machine; emulator and save paths remain machine-specific. PS5/custom PS4 integrations open the emulator interface only.

No emulators, firmware or games are included. Existing version-2 library data is preserved. Hub data is stored separately in features.json beside the library; save ZIPs are in save-backups.
