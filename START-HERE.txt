GoldenEmulator — Windows Stage 2 review

1. Extract the ZIP to a permanent folder.
2. Open GoldenEmulator.html in Edge or Chrome. Use the same browser and file location each time.
3. Click Import game folder, choose a console, then choose a folder with games for that console.
4. Review the detected files, deselect any unwanted entries, and click Add selected games.
5. Open a game to edit its title, console, notes, cover image or favourite status.
6. Use Library search, console filters and sorting. Settings includes Export backup and Restore backup.

Files stay on your drive. This build saves library metadata and cover artwork locally in IndexedDB; it does not copy or upload game files. Browsers expose relative paths, not full Windows paths. Actual emulator launch configuration comes in Stage 3.

Keep a backup before moving the HTML or clearing browser data. Backups contain artwork and metadata, not games. Use one GoldenEmulator window at a time; this build does not synchronize edits between open windows. Limits: 5,000 games, 20,000 files per folder scan, 45 MB saved library, 10 MB per input cover image (resized locally), 50 MB backup import.

Formats recognized:
GameCube: ISO, GCM, RVZ, CISO
Xbox 360: ISO, XEX (extracted games may expose more than one XEX; review selection)
PS2: ISO, BIN, CHD, CSO, CUE (matching BIN is skipped when CUE exists)
PS5: PKG, eboot.bin only (recognition does not imply playable support)
Archives are skipped. Updates, DLC and multidisc entries may appear separately; review before adding.
