GoldenEmulator — Stage 5 Windows review (0.5.0)

INSTALL
Run GoldenEmulator-Setup-0.5.0.exe, then use the GoldenEmulator shortcut.
The portable ZIP is optional: extract it into a new folder and run GoldenEmulator.exe.
If updating from Stage 3/4, first open the old browser tab and choose Settings > Exit GoldenEmulator.

OPEN / CLOSE
The small GoldenEmulator launcher window stays visible while the app runs.
Open game library opens the interface in your default browser.
Exit GoldenEmulator or the launcher's X button fully exits the launcher.
Closing only the browser tab leaves the launcher window running.
Start menu > GoldenEmulator > Stop GoldenEmulator also exits it.
Running emulators are not terminated. Close them normally.

SETUP AND PLAY
Settings > Emulator setup links your installed Dolphin, Xenia or PCSX2 EXE.
Import a game folder, open a game, and select Launch game.
Emulators, games, BIOS and firmware are not included. PS5 is library-only.

CONTROLLER
Focus the browser tab, press and release a controller button.
D-pad/left stick: navigate. A/Cross: select. B/Circle: back. LB/RB: pages.
Dropdown: A/Cross, then up/down to change, A/Cross or B/Circle to finish.
Use keyboard/mouse for text and Windows file pickers. Fullscreen: toolbar button or F11.
After gameplay close the emulator and return to the browser tab; release buttons before continuing.

YOUR DATA
Saved library: %LOCALAPPDATA%\GoldenEmulator\library.json
Emulator paths: %LOCALAPPDATA%\GoldenEmulator\emulators.json
Installation defaults to %LOCALAPPDATA%\Programs\GoldenEmulator.
Installing/reinstalling or uninstalling keeps the separate saved library/settings.
Settings > Export backup saves library entries/art, not games or emulator settings.
To move an old browser-only library: export there, restore in the Windows app, then Locate game file.

TROUBLESHOOTING
Already running: opening again reopens the current library. Exit the old launcher before an update.
For Stage 3/4, use Settings > Exit GoldenEmulator in its browser tab.
Missing game: use Locate game file. Missing emulator: choose its EXE again in Settings.
A damaged library is reported without resetting it; keep a copy before repairing it.
Launch failures: check the emulator itself, firmware/BIOS and game compatibility.

Limits: 5,000 games; 20,000 files per scan; 45 MB library; 10 MB source cover; 50 MB backup.
Use Check for updates in the launcher or Settings to find newer installers (including review releases). Downloads open on GitHub; exit the launcher before installing. This is an unsigned review release.

Check for updates is available in the launcher window and Settings. It compares installer versions on GitHub, reports when you are up to date, and offers the download page for newer versions, including review releases. Installation remains manual.
