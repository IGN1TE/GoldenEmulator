GoldenEmulator 0.9.0 — Desktop app

1. Exit the older version through Settings > Exit GoldenEmulator.
2. Run GoldenEmulator-Setup-0.9.0.exe.
3. Open the GoldenEmulator desktop or Start menu shortcut.

The library opens in a standalone desktop window. Close its X button to exit fully.
Opening the shortcut again restores the current window instead of opening a browser.
Settings > Check for updates downloads, verifies and installs new releases, then reopens GoldenEmulator.
The fullscreen toolbar button toggles desktop fullscreen.

Your saved library and emulator paths are kept in %LOCALAPPDATA%\GoldenEmulator.
Settings > Export backup saves library metadata and artwork, not game files or emulator paths.
The installer adds Microsoft WebView2 if missing (internet required). Portable ZIP users need the runtime already installed.

Controller: focus the app, press and release a button. D-pad/left stick moves; A/Cross selects; B/Circle goes back; LB/RB changes pages. Use keyboard/mouse for text and Windows file pickers.
Close emulators normally after gameplay and return to GoldenEmulator. Exiting GoldenEmulator does not terminate games.

Settings > Emulator setup: choose installed Dolphin, Xenia, PCSX2, Snes9x, Mesen, DuckStation, RPCS3 or shadPS4 / ShadPS4QtLauncher EXEs. Game compatibility depends on your installed emulator.
Import game folders or use Locate game file for old entries. Emulators, firmware, BIOS and games are not included. PS5 can connect and open KYTY or another emulator EXE. Select games inside that emulator.

Signing is deferred. The installer is unsigned and Windows may show SmartScreen warnings.

Hub opens watched folders, path repairs, collections, diagnostics, updates and couch mode.
Game page & settings contains artwork lookup, launch overrides, save backups, discs and playtime.
Controller: Y/Triangle searches; X/Square opens Hub; Start/Menu cycles collections.
